## 🚀 START HERE - Quick Reference

### To Debug Right Now:

1. **Reload Rider**
   ```
   File → Invalidate Caches → Invalidate and Restart
   ```

2. **Select Debug Config**
   - Toolbar dropdown → "Maui.Popes - Android Debug" or "Device"

3. **Start Debugging**
   - Press: **Cmd+D**
   - Or click: 🐛 Debug button

4. **Set Breakpoint**
   - Click in code gutter (left margin)
   - Red dot = breakpoint set

5. **Debug Controls**
   - F7 = Step Into
   - F8 = Step Over
   - F9 = Continue
